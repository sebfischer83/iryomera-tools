# Phase 4 — data-only ModKit

1. Merge the verified Phase 3 branch into main, retaining its history, then implement Phase 4 on `feature/phase-4-modkit`. Keep Phase 5/mod.io and the private patient simulator outside this work.
2. Extend SDK contracts additively with optional per-definition asset references and furniture placement (grid footprints and named interaction points). Reuse existing room/furniture, examination/resource, diagnostic, localization and dependency contracts. Synchronize v1 schemas and portable net8/net10 validation/tests without changing existing valid content identities.
3. Add `src/Iryomera.ModKit`, a .NET 10 CLI/tool with independently callable async project/validation/archive APIs. Reference SDK, Localization and the existing System.CommandLine package; no UI, database, Godot or distribution dependency. Add an xUnit project to the solution.
4. Specify a versioned local `mod.json` authoring manifest containing the existing SDK ModManifest plus explicit typed/licensed file inventory. Package the same file and declared payload into ZIP with a versioned `checksums.json` index. Validate original JSON against bundled offline schemas; preserve extensions. Content may be split across files, but package identity/version/namespace/dependencies must agree with the mod manifest.
5. Implement create, validated atomic file replacement, validate, pack, inspect and unpack commands. Use existing graph/dependency/localization checks; optionally check a supplied game version. Asset bindings must match declared files and licenses. Validate GLB container/JSON framing and embedded-only resources, and check allowed image signatures. No untrusted code, scripts, plugin assemblies, external asset URI loading or medical inference.
6. Bound archive/file/count/expanded-size/compression-ratio limits. Reject traversal, absolute/Windows-device paths, portable-name collisions, links/special files, undeclared files and hash/size mismatches. Extract into a fresh private staging directory and move atomically only after complete validation. Refuse existing destinations and clean up on failure/cancellation. Packing copies only declared files and detects changes during capture.
7. Generate an own MIT synthetic example mod with medical/game definitions, a GLB mesh, image asset, furniture footprint/interaction point, room requirements, independent balancing and full en/de catalogs. New project creation uses embedded data templates; no medical definition is hardcoded into business logic. Local authoring requires no network; medical review and upstream rights are never granted by packaging.
8. Test schema/legacy compatibility, assets/layouts, local dependency resolution, bilingual catalogs, actual CLI create/edit/pack/inspect/unpack, deterministic packaging and malicious/corrupt archives. Extend Windows/Linux CI with schema/example regeneration and a real CLI example. Run the full Release suite and packed Godot/Studio regressions; document observed results and remaining limits before declaring completion.
